# Landing image sources

The site has no photographs and no images from the internet (owner decision, 2026-11-24). No credit line is shown on the page.

The `showcase_*.webp` files are screenshots of this application, rendered from its own widgets with sample notes by `test/landing_screens_capture_test.dart`; they contain no third-party content. The illustrations, icons and state images of the landing are drawn in code (`components/sketch_art.dart`, `components/sketch_pen.dart`); they use no third-party icon or illustration pack.
